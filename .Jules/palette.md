# Palette's UX & Accessibility Journal

## 2023-11-20 - Monospace Text-based Affordances for Ultra-Minimalist Apps
**Learning:** In zero-vector-icon or extremely minimal-APK-size design patterns, standard material design icons might be intentionally omitted. Standard icons like `Visibility` or `VisibilityOff` are unavailable or create heavy icon dependencies. Using plain, styled text formatted as bracketed actions (e.g., `[Show]`, `[Hide]`, `[Paste]`) in a Monospace font provides a clean, clear text affordance that perfectly matches the technical aesthetic while remaining fully functional, keyboard-accessible, and highly readable without adding layout overhead.
**Action:** When adding inline actions in highly constrained minimalist environments, avoid vector icon dependencies by employing lightweight bracketed monospace text controls styled with the theme's primary color, proper padding, and descriptive state labels.
